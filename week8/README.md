# Week 8 — Closed-Loop Differential-Drive Robot

## Overview
Built and tested a physical differential-drive mobile robot, integrating DC motors, wheel encoders, an Arduino, an IMU and an ultrasonic distance sensor.

## Key Learning
- Implemented PI wheel-speed control using encoder feedback.
- Developed differential-drive odometry to estimate robot movement.
- Integrated MPU6050 IMU and HC-SR04 ultrasonic sensing.
- Tested autonomous movement, obstacle stopping and turning behaviour.
- Troubleshot motor performance and sensor integration.

## Outcome
Demonstrated approximately 0.5 m of forward movement, obstacle detection and stopping, a 90° turn, and continued movement.
