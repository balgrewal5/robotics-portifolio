# Week 12 — ROS 2 Robot Arm Control

## Overview
Implemented and tested a simulated 2-DOF robotic arm using ROS 2, Gazebo and the ros2_control framework.

## Key Learning
- Configured URDF robot descriptions with joints, links and physical properties.
- Integrated Gazebo simulation with ros2_control.
- Configured joint state broadcasting and joint trajectory controllers.
- Used controller YAML files to define controller behaviour.
- Implemented joint trajectory commands to control arm movement.
- Debugged controller configuration and RViz visualisation issues.

## Outcome
Successfully demonstrated a simulated robotic arm following commanded joint trajectories through the ROS 2 control framework.
