# Week 23 — Autonomous Robotic Manipulation

## Overview
Planned final Robotics Roadmap 1 portfolio project: developing a simulation-based autonomous pick-and-place system using a UR5e robot arm in Webots.

## Project Objectives
- Integrate Webots simulation with ROS 2.
- Use camera perception to detect target objects.
- Apply TF2 and coordinate transformations.
- Implement collision-aware motion planning with MoveIt 2.
- Execute autonomous pick-and-place operations.
- Evaluate grasp success, positioning accuracy and execution time.
