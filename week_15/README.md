# Week 15 — SLAM and Autonomous Mapping

## Overview

Explored Simultaneous Localisation and Mapping (SLAM) using ROS 2, TurtleBot3, Gazebo and slam_toolbox.

## Key Learning

- Understood occupancy grid mapping and robot localisation.
- Used TurtleBot3 in a simulated environment.
- Configured ROS 2 mapping using slam_toolbox.
- Visualised laser scans, TF frames and map updates in RViz.
- Teleoperated the robot to explore and map its environment.
- Saved the generated occupancy grid map.

## Outcome

Successfully performed simulated SLAM mapping with TurtleBot3, observing real-time map generation at approximately 2.5 Hz.

This week provided practical experience with ROS 2 mapping workflows and their role in autonomous navigation.
