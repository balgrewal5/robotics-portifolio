# Week 16 — Vision-Enabled Mobile Robot Integration

## Overview

Integrated computer vision, ROS 2 and embedded motor control to develop a physical mobile robot capable of rotating to track a detected object.

This project combined learning from previous weeks in electronics, programming, ROS 2 and computer vision.

## Key Learning

- Integrated a Raspberry Pi and Arduino for robot control.
- Applied YOLO-based object detection using a USB camera.
- Used image-centre error to determine steering corrections.
- Developed a ROS 2 detection-to-control pipeline.
- Implemented rotation-only object tracking.
- Tuned motor PWM commands to improve tracking stability.
- Debugged communication and physical robot behaviour.

## Outcome

Successfully demonstrated a physical differential-drive robot rotating in place to track a detected object.

The robot did not drive forwards or backwards during the final demonstration.
