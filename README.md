# Robotics Roadmap 1 — Weekly Learning Repository

A self-directed robotics engineering learning journey undertaken alongside my MSc in Robotics.

This repository documents my progression from programming and electronics fundamentals towards developing integrated robotic systems.

## Purpose

To build practical engineering knowledge through consistent hands-on learning, experimentation, programming and problem-solving.

This repository serves as a chronological learning archive, demonstrating the development of my robotics skills over time.

## Areas Covered

- Python and C++ programming
- Electronics, Arduino and Raspberry Pi
- Sensors, actuators and motor control
- ROS 2, Linux and robot simulation
- Robot kinematics and control
- Computer vision and perception
- SLAM and autonomous navigation
- Motion planning and robotic manipulation
- Machine learning and reinforcement learning

## Weekly Progress

**Weeks 0–4:** Foundational programming, robotics and control exercises.

**Weeks 5–22:** Embedded systems, ROS 2, perception, navigation, planning, control and intelligent robotics.

*Earlier weekly work is being progressively archived into this repository.*

## Repository Structure

Each weekly folder contains selected code, experiments or brief technical notes representing the learning undertaken that week.

This is a working learning archive rather than a collection of polished portfolio projects.
